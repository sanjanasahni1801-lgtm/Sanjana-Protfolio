# Sanjana Sahani Portfolio — optimized work gallery

This version is optimized around the supplied portfolio direction.

## My Work behavior
- All: only a curated selection of posters, videos, writing and Instagram/social-media work.
- Posters: all 64 supplied poster/image files, shown with `object-fit: contain` so original proportions are preserved.
- Clicking a poster opens a fullscreen zoom viewer with previous/next navigation.
- Videos: 2 supplied MP4 videos with responsive native playback.
- Writing: 5 separate article samples, each opening in its own focused reading view.
- Social Media: Instagram-oriented presentation for reels, carousels, campaigns, captions, stories and engagement.

## Home
The old SS placeholder has been replaced by an automatic slideshow using real uploaded posters, videos and writing samples. It changes automatically and also has previous/next controls and dots.

## Important placeholders
Replace:
- `YOUR_EMAIL@gmail.com`
- LinkedIn URL
- Instagram URL / @yourusername
- Twitter/X URL

## Adding more work
Put images into `assets/images/` and videos into `assets/videos/`. For additional writing samples, add them to the `articles` data in `index.html`.

Open `index.html` locally to preview.
